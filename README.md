# 1CCR · Python · FIAP 2026

Exercícios e atividades de Python do 1º ano de Ciência da Computação na FIAP (turma 1CCR), organizados por aula.

## Conteúdo

- **Aula 02:** variáveis e operadores
- **Aula 03:** módulos, funções, condicionais, operadores lógicos e match-case
- **Aula 04:** laços while e for
- **Aula 05:** strings, arrays e matrizes
- **Aula 06:** revisão, com um desafio de consumo de API
- **Aula 07:** dicionários e tuplas
- **Aula 08:** mini-CRM de leads, separado em model, control e app, com dados em arquivo
- **Aula 09:** orientação a objetos (classes Aluno e Disciplina)

## Como rodar

Requisito: Python 3.10 ou mais recente.

```bash
python aula04-repeticao/aula04b-for.py
```

Cada arquivo roda de forma independente. Nas aulas 08 e 09, rode o `app.py` de dentro da pasta da aula.
